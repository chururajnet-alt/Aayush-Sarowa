Origins & System Engineering Path

I am Aayush Sarowa, a 12-year-old software engineer and student currently studying in the 7th Standard at PM Shri Kendriya Vidyalaya, Churu (born February 10, 2014). My curiosity in computing started early with hardware architectures, memory layout constraints, and bit-level transformations under Linux.

Fascinated by silicon speed and combinatorial search, I built GoChess—an AVX2-vectorized bitboard chess engine featuring Principal Variation Search and NNUE evaluation weights. Creating an engine evaluating millions of nodes per second shaped my philosophy on data locality, cache coherency, and zero-allocation memory pools.

Extending these concepts into distributed systems led me to design and develop the Super Tracker telemetry platform: an enterprise-ready pipeline providing real-time transit telemetry, geofence processing, and sub-second fleet dispatch for schools and municipal networks.
